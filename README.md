# KosherDialer

אפליקציית חייגן לאנדרואיד בעיצוב Material 3: חיוג, אחרונות ואנשי קשר.
אנשי הקשר ויומן השיחות נמשכים בבלוטות' (PBAP) ממכשיר מצומד, והשיחה מתבצעת במכשיר האנדרואיד עצמו דרך מסך השיחה של המערכת.

## בנייה
1. פתיחה ב-Android Studio וסנכרון Gradle.
2. Build > Build APK(s).

## דרישות
- Android 8.0 ומעלה.
- המכשיר המצומד חייב לתמוך ב-PBAP ולאשר שיתוף אנשי קשר.
